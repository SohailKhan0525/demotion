The second demotion launch film: **30 seconds, 1920×1080, 60 fps**, with a
procedural 128 BPM soundtrack. Download `demotion-v2-launch.mp4` below and upload
the file directly to your chosen platform. `poster.png` is the opening frame;
`SHA256SUMS` verifies the downloads.

**“V2” names this film, not an npm 2.0 release.** The new CountUp, BarChart,
CaptionTrack, LowerThird and ProgressRing components are in the tagged source.
The film identifies them as a source preview; npm 0.1.0 contains the original
toolkit. See the current README and registry for later package-release status.

- [Platform-specific launch posts](https://github.com/SohailKhan0525/demotion/tree/launch-v2/docs/launch-v2)

performance claims. It has music and effects, with essential information written
