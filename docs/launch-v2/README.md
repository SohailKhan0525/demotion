## Publish in a useful order

1. Download the MP4 and play it. Use the native upload, not a link preview, on
   platforms where video uploads are allowed. The poster is the opening frame.
2. Start with the X post and installation reply, then answer real questions.
3. Publish the DEV tutorial after reviewing it and checking current DEV rules.
   Its frontmatter remains `published: false`, with an AI disclosure field.
4. Check the chosen subreddit's current rules, pinned threads and submission
   restrictions before using the Reddit draft. Live rules could not be read here;
   a draft is not approval to post. Use a designated thread if required.
5. Adapt the additional platform copy where you already participate. Avoid
   mass-crossposting, engagement requests and unsolicited messages.

The five new components are on main, not npm 0.1.0. Source-candidate instructions
are included. The manual npm Release workflow is separate from the film workflow;
update the launch copy only after a new registry release and consumer check.

No social posts have been sent. There is no guarantee of reach; prioritize a
developer successfully making a first render and adapting an example.
