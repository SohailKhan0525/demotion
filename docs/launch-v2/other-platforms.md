```text
I wanted video components I could reuse the way I reuse React components.

So I built demotion on Remotion: write a scene in code, preview it, and render an MP4 locally.

For this second demo, I added five building blocks: counters, charts, captions, lower thirds and progress rings. They share a beat clock, and their output stays deterministic when seeking backward or rendering frames out of order.

The attached 30-second film was generated with the toolkit. The chart values illustrate its timeline; they aren't usage or performance claims.

The original starter is on npm as @demotion/cli. The new components are on GitHub main, with a complete data-story example; npm 0.1.0 does not include them yet.
```
