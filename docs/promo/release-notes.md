# Ideas deserve motion

A new Demotion promo film: **56 seconds · 1920×1080 · 60 fps**.

Original floating frame artwork, readable product demonstrations, spring
animation and a procedural soundtrack, all generated from the repository.

Download `demotion-promo-launch.mp4` below. `poster.png` and `SHA256SUMS` accompany
it. These are film assets, not a new npm release.

- [Source and reproduction instructions](https://github.com/SohailKhan0525/demotion/tree/promo-launch/docs/promo)
- [Working four-second React example](https://github.com/SohailKhan0525/demotion/blob/promo-launch/examples/promo-scene.tsx)
- [Published package](https://www.npmjs.com/package/@demotion/cli)
- [Delivery verification](https://github.com/SohailKhan0525/demotion/blob/main/docs/promo/verification.md)

The original toolkit is published as `@demotion/cli@0.1.0`. New data and caption
components shown in the film are source previews and are not in npm 0.1.0.
