# Reference study and film direction

The owner supplied `x-downloader.com_gJonJ7.mp4` as a visual reference. Its visible
branding is OpenDuet / CopilotKit. The file is 1920×1080, 30 fps, approximately
69.6 seconds, with stereo AAC. Authorship and asset rights were not independently
verified. This is a study of the supplied video, not evidence about that product's
features or performance.

Observed from a whole-video contact sheet at two-second intervals and a six-fps
sample near the 30-second transition: light backgrounds, small brand marks,
generous spacing, large readable headlines, floating objects, then sustained
left-copy/right-product scenes. Successive captions change while the product
frame persists. The film gives demonstrations room to settle. Its final section
returns to a centered call to action.

This Demotion film carries over that reading pace and product-first structure.
It uses original artwork, layouts, copy and a synthesized score. No reference
footage, UI, mascot, logos or soundtrack is embedded or redistributed.

## Design brief

- Audience: React developers and creators evaluating a code-based video toolkit.
- Task: understand what Demotion does, see working components, find the real CLI.
- Success criterion: readable examples, truthful availability, a reproducible
  source composition and a verified downloadable MP4.
- Direction: a light worktable of floating video frames. Chalk surfaces and blue
  headlines use the existing five-color palette and bundled Archivo family.
- Avoided directions: the previous film's rapid, saturated full-screen cuts would
  work against the supplied reference's pace; copying its agent mascot and mobile
  app UI would misrepresent Demotion's actual product.

| Device | Purpose | Cost / simpler alternative |
| --- | --- | --- |
| Layered D / play frame sculpture | Connect components, frames and video; repeat a recognizable identity | CSS/SVG depth and shadows; a flat mark is used in the small header |
| Floating code and output panels | Show the relationship between source and rendered content | Perspective needs legible angles; keep code nearly face-on |
| Left headline / right demonstration | Keep the benefit visible while a component animates | Repetition is broken by centered opening, workflow, gallery and ending |
| Restrained spring entrances | Give objects weight while preserving reading time | Short stagger, then hold; no unrelated perpetual effects |
| Beat clock and original score | Align visual events with sound | Adds render time; all meaning also appears as text |
| Real render-time motion blur and subtle grain | Smooth moving objects and soften the scene | Four sub-frame samples; no full-screen flashing transitions |
