# Draw it. Give it depth.

The Demotion illustration-update film: **40 seconds · 1920×1080 · 60 fps**.

An original SVG mark draws itself, objects follow its curves, and real extruded
geometry assembles into a layered sculpture. `DrawPath`, `FollowPath` and
`WorkflowIllustration` share a beat clock with `Scene3D`, `ExtrudedSvg` and an
original procedural score.

The `update-030` tag identifies this separate film prerelease. The asset workflow
verifies the encoded media before uploading the downloads below.

Download `demotion-update-030.mp4`, `poster.png` and `SHA256SUMS` from this release.
Check the downloaded assets with `sha256sum --check SHA256SUMS`.

- [Source, storyboard and reproduction](https://github.com/SohailKhan0525/demotion/tree/update-030/docs/update-film)

The film contains original artwork and music; reference footage and other
products' interfaces, branding and soundtracks are not embedded. Film assets
and npm publication use separate workflows. Demotion's existing license terms
apply; Remotion has separate terms.
