# Changelog

## 0.1.0 — 2026-10-26

Initial toolkit release as `@demotion/cli` in the `demotion` npm organization.

- CLI project scaffolding with bundled fonts and a React/Remotion starter.
- Main React component API, beat clock, spring/easing helpers and scene engine.
- Terminal and code-panel reveals; optional 3D panels with depth of field.
- Procedural audio API and CLI with beat-based cues and loudness mastering.
- Generated-project 1080p and 4K render scripts.
- Tested README examples, package types and installation instructions.
