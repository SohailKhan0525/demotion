# __NAME__

A video made with [demotion](https://github.com/SohailKhan0525/demotion) — motion graphics, written in code.

```bash
npm install
npm start           # live preview in the browser
npm run render      # out/video.mp4   (1920x1080)
npm run render:4k   # out/video-4k.mp4 (3840x2160)
```

Edit `src/MyVideo.tsx`. Everything renders on your own computer.
